# ZabDesk – SZABIST Mobile App Wireframe

## 📱 Project Overview

ZabDesk is a high-fidelity mobile application wireframe designed for the Shaheed Zulfikar Ali Bhutto Institute of Science and Technology (SZABIST) as part of the Human–Computer Interaction (HCI) Theory course.

The project was created in Figma and aims to provide students with a modern, user-friendly, and accessible mobile experience by bringing together essential academic services into a single platform.

The design is inspired by SZABIST's academic ecosystem and website structure while applying user-centered design principles, interaction design guidelines, and HCI concepts to improve usability and overall student experience.

---

## 🎯 Project Objectives

- Improve student accessibility to academic services
- Create an intuitive and user-friendly mobile experience
- Apply Human–Computer Interaction (HCI) principles
- Ensure visual consistency across all screens
- Design a modern and engaging academic platform
